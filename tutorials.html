入门教程

Minecraft 新手快速开始

这是本站推荐的新手流程。实际资源版本更新后，以资源页面中的具体说明为准。

1. 准备启动器

第一步
进入 启动器页面，选择一个适合自己的启动器。

2. 准备 Java

第二步
根据准备游玩的 Minecraft 版本安装对应 Java 环境。启动器通常可以辅助管理 Java。

3. 安装游戏

第三步
在启动器中创建或安装目标 Minecraft 版本，首次启动建议保持默认配置。

4. 安装资源

第四步
如果使用整合包、光影或材质包，请继续阅读对应专项教程。

5. 第一次进入游戏

首次进入时先确认游戏能够正常启动，再逐项增加 Mod、光影与材质包。这样出现问题时更容易判断原因。

启动器

PCL2 安装与基础配置

资源页面提供下载入口。本教程只描述通用安装思路，具体界面可能随版本变化。

安装

1. 下载 PCL2 后运行程序。
2. 按启动器提示完成基础设置。
3. 安装目标 Minecraft 版本并首次启动。

推荐检查

  • 游戏目录是否放在容易管理的位置。
  • Java 是否被启动器正确识别。
  • 首次启动是否能够进入主菜单。
启动器

HMCL 安装与基础配置

HMCL 的核心流程同样是：启动器 → Java → 游戏版本 → 启动测试。

基础流程

  1. 下载并打开 HMCL。
  2. 检查 Java 环境。
  3. 安装 Minecraft 版本。
  4. 第一次启动确认环境正常。
整合包

Xplus 整合包安装教程

如果你使用本站的 Xplus 基础优化整合包，建议先确保对应 Minecraft 与加载器版本匹配。

安装流程

1. 下载整合包文件。
2. 根据启动器提供的整合包导入功能完成导入。
3. 检查 Mod 与游戏版本是否对应。
4. 启动游戏测试。
光影

Minecraft 光影安装教程

基础流程

  1. 先确认已经安装支持光影的加载器或相关组件。
  2. 下载对应版本的 Shader。
  3. 将 Shader 文件放入游戏的 shaderpacks 目录。
  4. 进入游戏视频设置中启用。
